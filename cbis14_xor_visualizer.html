Bitwise Operators Guide

How each operator manipulates binary data.

AND (&)

Returns 1 only if both bits are 1. Acts as a strict filter.

  • 1 & 1 = 1
  • 1 & 0 = 0
  • 0 & 0 = 0

OR (|)

Returns 1 if either bit is 1. Guaranteed to turn a bit on.

  • 1 | 1 = 1
  • 1 | 0 = 1
  • 0 | 0 = 0

XOR (^)

Returns 1 if bits are different. Toggles bits and encrypts data.

  • 1 ^ 1 = 0
  • 1 ^ 0 = 1
  • 0 ^ 0 = 0

NOT (~)

Inverts the bits. Turns 1 into 0, and 0 into 1.

  • ~1 = 0
  • ~0 = 1

Left Shift (<<)

Pushes bits left, adding 0s on the right. Multiplies by 2.

  • 0010 << 1 = 0100
  • 0100 << 2 = 10000

Right Shift (>>)

Pushes bits right, removing bits on the edge. Divides by 2.

  • 0100 >> 1 = 0010
  • 0010 >> 2 = 0000
